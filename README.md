# Web Personal — Trigal Naciente Oliva Campusano

Portafolio y página web personal de **Trigal Naciente Oliva Campusano** (Ingeniería Industrial | Técnica en Control Industrial | Gestión Logística | Training PNL).

🌐 **Sitio web en vivo (Cloudflare Pages):** [https://web-personal-cloudflare-k3e.pages.dev/](https://web-personal-cloudflare-k3e.pages.dev/)

## Estructura del proyecto
- `index.html`: Estructura principal y contenido del perfil profesional.
- `style.css`: Diseño visual inspirado en geometría orgánica y bambú, adaptable a dispositivos móviles (responsive) y con modo claro/oscuro.
- `script.js`: Interactividad de navegación, cambio de tema, animaciones de scroll y formulario de contacto.
